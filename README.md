# Hayru Şifa — Website Redesign Project

The old site `https://hayrusifa.com.tr/` (WordPress) was fully crawled, all content was collected as text, and it was reorganized into a clean new category structure. This folder is the content source for the new site (plain HTML/CSS).

**Live:** https://canberkeh.github.io/Hayrusifa/ (GitHub Pages, `gh-pages` branch)
**Repo:** https://github.com/canberkeh/Hayrusifa (public)

## Deployment

- **Source:** `main` branch. The project root uses absolute paths (`/assets`, `/blog`) and targets the root of `hayrusifa.com.tr`.
- **GitHub Pages:** the `gh-pages` branch is produced by `crawl/scripts/deploy-ghpages.sh`. It rebuilds the site, prefixes paths with `/Hayrusifa/` (project-site sub-path) and force-pushes to `gh-pages`. Pages updates within 1–2 minutes.
  ```
  bash crawl/scripts/deploy-ghpages.sh
  ```
- **Automatic deploy (optional):** `.github/pages.yml.disabled` is a ready-made GitHub Actions workflow. To enable it, run `gh auth refresh -s workflow`, move the file to `.github/workflows/pages.yml` and push. Every push to `main` then publishes `site/`. Set the Pages source to "GitHub Actions" in that case.
- **Real domain (`hayrusifa.com.tr`):** put the contents of `site/` directly at the domain root; no path prefix is needed.

## Generated Site (`site/`)

Plain HTML/CSS/JS, no framework. Generated by `crawl/scripts/build_site.py`.

| Page type | Count | Path |
|---|---|---|
| Home page | 1 | `site/index.html` |
| Blog home (category showcase) | 1 | `site/blog/index.html` |
| All posts (searchable / filterable list) | 1 | `site/blog/tum-yazilar.html` |
| Category pages (by method, grouped by sub-topic) | 21 | `site/blog/<method>/index.html` |
| Blog posts | 590 | `site/blog/<method>/<slug>.html` |
| Corporate pages (about, contact) | 2 | `site/*.html` |
| 404 | 1 | `site/404.html` |
| Plus `sitemap.xml`, `robots.txt`, `_redirects` (old slug → new URL, 301) | | |

**Preview:** `cd site && python3 -m http.server 8000`, then open `http://localhost:8000`. Absolute paths are used, so `file://` will not work; a server is required.

**Design:** `crawl/scripts/site.css` (single stylesheet) and `crawl/scripts/site.js` (mobile menu + post filtering). Based on the Wix "Pilates Studio (Refined)" (wh-1323) template.
- **Header:** dark blue (`#0433bf`) bar with the menu centered/right
- **Hero:** split layout with a dark navy (`#1e2a38`) text panel and an image, plus a thin lime lotus motif
- **Typography:** Space Grotesk (headings) + Inter (body); logo in Cormorant Garamond
- **Palette:** navy + lime + warm off-white (`#f7f5ef`) + sage
- **Home hero image:** set by the `HERO_IMAGE` constant in `build_site.py`; it can be swapped for any other file under `/assets/img/`

**Blog structure:** `/blog/` shows the 14 main methods as cards (with post counts). Each `/blog/<method>/` page lists that method's posts grouped by sub-topic (What Is It, Benefits, How It Is Applied, Side Effects, …).

The contact page has no form; it offers phone/WhatsApp/email, a Google Maps embed and an "Open in Maps" link. (Map tiles appear blank on localhost and render once published.)

**Hijri Cupping (Hacamat) Days:** each year a calendar post converts the 17th/19th/21st days of the Hijri months (the traditional cupping days after the full moon) into Gregorian dates. Posts `2026-hacamat-gunleri` and `2027-hacamat-gunleri` exist. Hijri month starts follow the Diyanet calculated calendar and were cross-checked against the official Ramadan/Eid al-Adha/Hijri New Year dates. A post for the next year should be added each year using the same method (e.g. 2028 at the end of 2026).

**Known gaps:** corporate pages for the doctor and team do not exist yet (to be added to `hakkimizda.html` once the information is available); about 12 older posts have no featured image (a category-labelled placeholder is used); internal links inside old posts have not yet been mapped to the new URLs.
